# C++ ANTLR lexer

`CPP14Lexer.g4` is an unmodified copy of the grammars-v4 C++ lexer at commit
[`e756f2a2ee5565a9300666f100ba6acd874664f7`](https://github.com/antlr/grammars-v4/blob/e756f2a2ee5565a9300666f100ba6acd874664f7/cpp/CPP14Lexer.g4).

- Upstream directory: <https://github.com/antlr/grammars-v4/tree/master/cpp>
- Upstream blob SHA: `1c64639323c0c72e5452130dc267d0b01a8f5618`
- Local SHA-256: `739a8782e05279318dccab76bf05af1ff5e3ff9e43f1b5b0d04e14d91d4fff47`

The Gradle ANTLR Kotlin task generates `CPP14Lexer.kt` under `build/generatedAntlr`;
generated source is intentionally not checked in.
